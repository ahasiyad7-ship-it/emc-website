# EMC Web Page

EMC Web Page project built with HTML. Includes course sections, YouTube video embed, and student registration form.

🚀 **Live Website:** https://ahasiyad7-ship-it.github.io/emc-website/

## 📌 Features
- Course Sections - Detailed course information
- YouTube Video Embed - Embedded learning videos
- Student Registration Form - Simple registration for students

## 🛠️ Built With
- HTML

## 📂 Pages
- `index.html` - Main page with courses and video
- `register.html` - Student registration form

## ▶️ How to Run
Open `index.html` in any browser.
